## 2. 架构总览(四角色协作)

```
大模型 = 大脑(决策+理解)    本地正则 = 反射(简单指令秒回)
OCR/UIA = 手(精确执行)      视觉模型 = 眼睛(看懂屏幕,只给区域不给坐标)
```

```
用户指令 → ①双速分流(本地正则)
  ├─ 简单 → 快速路径:正则解析动作+目标 → 直接执行 → 完成(<1s)
  └─ 复杂 → 深度路径:Agent循环(主LLM function calling)
        → 视觉模型描述截图(语义区域) → LLM决策 → 工具执行(UIA/OCR定位)
        → verify验证 → 反馈
```

## 5. 关键决策记录(含实测证据)

| 决策 | 结论 | 证据 |
|---|---|---|
| 定位坐标 | **永远用 OCR/UIA,不用视觉坐标** | 视觉把"+"认成另一个"+"(实测翻车) |
| UIA 定位 | **机会型加速器,不做主力** | 连原生资源管理器快速探测都几乎空;游戏100%无效 |
| 最小化窗口 | UIA 可读;视觉需先无焦点恢复 | 实测 SW_SHOWNOACTIVATE 不抢焦点 |
| 游戏防护 | 高风险窗口默认拒绝操作 | 实测 WeGame 运行中 |
| 多匹配消歧 | 视觉定区域 + OCR 定坐标 | 实测"会话"3 命中 |
| 双速推理 | 简单正则秒回,复杂走 LLM | 日常 60-70% 短指令可覆盖 |
| 独立产品 | 不依赖 Hermes,开源库实现能力 | 用户需求确认 |
